# Consciousness Theory Literature Excavator

Public release: *Under Any Name* (SE&RCH pilot). This copy has no git history and omits third-party text; see "What is not included and why".

A solo hackathon project (due 2026-10-16). For five theories of consciousness taken from Kuhn's
[Landscape of Consciousness](https://loc.closertotruth.com/) (LoC), it finds the associated literature at three levels:

1. **References.** The reference lists on each theory's LoC page, resolved to DOIs and open full text where possible.
2. **Direct mentions.** Open-access papers whose full text names the theory (strong terms plus cognitive-science context),
   with counts and snippets. This is the keyword baseline.
3. **Conceptual associations (the core).** Papers whose text is close in meaning to the theory's core claims but that
   **never name it**, found by embedding similarity and checked by an LLM judge.

Theories: Champagne's semiotic account, Global Workspace Theory, Integrated Information Theory, Panpsychism, and
Predictive Processing / Free Energy Principle.

## Run the app
The app reads only the tracked tables in `results/`. It needs no database, models or network access.

```
python3.11 -m venv .venv
.venv/bin/python -m pip install -r app/requirements.txt # streamlit and pandas only; no torch, sentence-transformers or database needed
.venv/bin/python -m streamlit run app/app.py             # opens http://localhost:8501; stop with Ctrl+C
```

The root `requirements.txt` is for the pipeline and the tests (it also installs torch and sentence-transformers); the app does not need it.

Tests: `.venv/bin/python -m pytest -q` (needs the root `requirements.txt`). The demo script is `docs/demo_script.md`, generated by `python app/build_demo.py`
from `results/` (so its numbers always match the tables).

## How the results were produced
Every stage reads and writes SQLite (`data/excavator.db`) or files under `data/`, is re-runnable, and caches HTTP responses.
One pointer per prompt in `prompts/`:

| Prompt | Stage | Code | Report |
|---|---|---|---|
| 01 | Scrape LoC pages, parse references, resolve DOI/PMCID/open access | `src/level1_extract.py`, `parse.py`, `resolve.py`, `oa.py` | `reports/level1_resolution.md` |
| 02 | Europe PMC corpus (1995-2015) and the Level 2 term scanner | `src/corpus/`, `src/level2_terms/`, `src/terms.yaml` | `reports/corpus_step1.md`, `level2_terms.md` |
| 03 | Optional second source (CORE) | superseded by prompt 09 | n/a |
| 04 | Concept profiles, chunking, embeddings (bge-base), contrastive retrieval | `src/level3_concepts/`, `profiles/` | `reports/level3_first_look.md` |
| 05 | Term-masked evaluation, discriminability, hand-label sheet | `src/eval/` | `reports/level3_eval_*.md`, `level3_discriminability.md` |
| 06 | Blind LLM judge on the top 30 per theory | `src/judge/`, `prompts/judge_rubric.md` | `reports/level3_judge.md` |
| 07 | 2016-2025 window, out-of-time test, app exports | `src/corpus/build_late.py`, `src/level3_concepts/late.py`, `src/export.py` | `reports/level3_out_of_time.md`, `level3_windows.md` |
| 08 | Streamlit app, demo script, this README | `app/`, `docs/` | n/a |
| 09 | CORE philosophy pilot (Champagne, panpsychism): separate, exploratory, judge on hold | `src/corpus/core*.py`, `build_core.py`, `src/eval/core_pilot.py`, `core_export.py` | `reports/core_pilot.md` |

Method in brief: papers that name a theory (Level 2) are excluded from Level 3. Each theory has a concept profile (LoC
description, reviewed core claims). Paper passages are scored by embedding similarity to the profile (z-scored; the selected
variant is V4). Evaluation masks the theory's names in papers that name it and tests whether the profile still ranks them
above other papers, against a BM25 keyword baseline. The judge rates the top 30 per theory.

## Data sources and acknowledgments
- **Landscape of Consciousness** (Robert Lawrence Kuhn; Closer To Truth, https://loc.closertotruth.com/) supplies the theory text and reference lists. The app quotes at most two sentences per theory with a link; follow the site's terms if you reuse more.
- **Europe PMC / PubMed Central open access** (REST API) is the corpus: full text, JATS XML.
- **Crossref** resolves reference strings to DOIs; **Unpaywall** finds open-access copies of DOIs not in PMC.
- **OpenAlex** is used for discovery only (DOI and open-access lookups); no citation graph is built from it.
- **CORE (core.ac.uk)** supplies the exploratory philosophy pilot (prompt 09) only. The API returns no license field, and CORE's terms limit the data to machine processing and do not authorise redistributing the works, so CORE text is never tracked; `results/philosophy_pilot_*.csv` hold titles, links, scores and counts only. If you show these results, cite CORE using the citation given on https://core.ac.uk.
- **BAAI bge-base-en-v1.5** (`BAAI/bge-base-en-v1.5`) is the embedding model.
- **Public data only.** No sensitive, personal or student data is used.
- Secrets live in `.env` (see `.env.example`), never committed. Requests use a descriptive User-Agent with a contact email.

## What is not included and why
- **Full texts of papers** (Europe PMC / PubMed Central open access and CORE): third-party works with their own licences. The pipeline re-downloads the Europe PMC texts.
- **Embeddings, the SQLite database and HTTP caches**: derived from those full texts.
- **Landscape of Consciousness page text and saved pages**: third-party text. `profiles/*.yaml` keep only the author's core claims, ids and sources; `make_profiles.py` regenerates the rest (see `profiles/README.md`). `results/theory_descriptions.csv` keeps two attributed sentences per theory with the source URL.
- **Paper abstracts used as profile seeds**: removed from the profiles.
- **CORE title, link and id lists and hand labels** (`philosophy_pilot_top.csv`, `core_pilot_labels.csv`): withheld pending CORE's response on licensing. Only counts and scores (`results/philosophy_pilot_metrics.csv`) are published.
- **Test fixtures** (saved LoC pages and a PMC article): the tests that need them are skipped with the reason "fixture not published".
- **Snippets** in `reports/` and `results/` are cut to 150 characters. Three "Personal communication" reference entries naming individuals were removed from `results/level1_references.csv` and `reports/level1_resolution.md`.
- See `THIRD_PARTY.md` for sources and terms.

## Main limitations
- **Open access only.** Coverage skews to neuroscience, psychology and medicine; panpsychism and Champagne are thin.
- **Small samples.** Champagne, IIT and panpsychism have 3, 17 and 7 test positives in 1995-2015 (exploratory).
- **Negatives are unlabeled**, so AUCs are lower bounds. The candidate-only AUC is the more informative number.
- **The judge is an LLM**, not ground truth (agreement with hand labels was moderate). Only the 1995-2015 top 30 per theory
  were judged; later-window papers are shown as "not judged".
- **Keyword ranking is competitive.** The conceptual method leads on GWT at the top 30 only, ties or loses on predictive
  processing, and the out-of-time AUC dropped for every theory.
- **2016-2025 lists are capped samples**; totals and trends come from full Europe PMC counts. The profiles use current LoC
  text, so the out-of-time test checks generalization, not forecasting.
- Champagne, IIT and panpsychism are the most confusable group in the discriminability matrix.
